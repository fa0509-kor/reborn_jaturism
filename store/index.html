  4. 04 접으면 손바닥 크기 납작하게 접어 가방 한쪽에 보관. 자리를 거의 차지하지 않음.

결제 방법

계좌이체만 가능, 카드 결제 없음. 주문 접수 시 입금 금액과 계좌 표시. 입금 확인 후 발송.

수령 시기

입금 확인 후 3일 안에 택배 발송, 발송 시 문자 안내. 직접 수령은 고려대 인근, 입금 확인 후 문자로 시간 조율.

색상 선택

자투리 원단 특성상 같은 색 중복 없음. 원하는 색은 '하고 싶은 말'에 적으면 가능한 범위에서 반영.
